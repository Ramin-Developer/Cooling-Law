The numerical solver in \texttt{src/DiffSol.m} uses a uniform time grid:
\begin{equation}
t_i = t_{\min} + i h, \qquad i=0,1,\ldots,N, \qquad
h = \frac{t_{\max}-t_{\min}}{N}.
\label{eq:time-grid}
\end{equation}

As visualized in Figure~\ref{fig:discretization-nodes}, increasing $N$ reduces
$h$ and provides a finer temporal representation.

The discrete unknown vector is
\begin{equation}
\mathbf{u} = [\bar{T}_1,\bar{T}_2,\ldots,\bar{T}_N]^\top,
\label{eq:discrete-unknown}
\end{equation}
where $\bar{T}_0=T_0$ is prescribed by Eq.~\eqref{eq:initial-condition}.

The implemented algebraic system has the tridiagonal form
\begin{equation}
\mathbf{A}\mathbf{u}=\mathbf{b},
\label{eq:linear-system}
\end{equation}
with row equations
\begin{align}
2kh\,\bar{T}_1 + \bar{T}_2 &= 2kh\,T_{\infty}+T_0, \label{eq:first-row} \\
-\bar{T}_{i-1}+2kh\,\bar{T}_i+\bar{T}_{i+1} &= 2kh\,T_{\infty}, \quad i=2,\ldots,N-1, \label{eq:interior-row} \\
-2\bar{T}_{N-1}+2(1+kh)\bar{T}_N &= 2kh\,T_{\infty}. \label{eq:last-row}
\end{align}

The sparse triplet assembly of Eq.~\eqref{eq:linear-system} keeps memory usage
low while preserving deterministic behavior. The resulting temperatures are
stored in \texttt{TempNum = [T0; u]}, matching the boundary condition exactly
at the first grid point.
